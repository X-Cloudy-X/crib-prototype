# Changelog

## Prototype v2 — feedback pass — 27 October 2026

This iteration applies usability feedback from a classmate review while preserving the current Assessment 1 scope.

### Changed

- Clarified the landing page so CRiB's purpose is understandable before entering the app.
- Explained that CRiB is intended as one interface for supported cloud-storage accounts.
- Kept Google Drive as the first simulated provider while showing OneDrive and Dropbox as planned providers.
- Renamed the main navigation to:
  - Dashboard
  - Browse files
  - Connected providers
- Removed the confusing duplicate Account/provider-management navigation.
- Consolidated provider connection, status and disconnection into Connected providers.
- Changed sign-up field `Name` to `Username`.
- Reworked simulated authorization copy so permissions explain what the user will actually see.
- Rewrote the expired-connection state to clearly explain what failed and what reconnecting does.
- Reduced repeated privacy/password messaging.
- Clarified that the current file browser is the normalized interface other providers would use later.
- Documented future transfer/NAS ideas as future direction rather than current prototype functionality.
- Expanded README documentation to explain:
  - Penpot as the design reference;
  - GitHub Pages as the current interactive prototype host;
  - dedicated hosting as a later team decision;
  - current prototype scope and limitations.
